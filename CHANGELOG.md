# Changelog

The release notes for each version of CS2 Server Manager (csm) are in two places, and they are the same notes:

- **[Changelog in the docs](https://docs.autotournament.gg/reference/changelog/csm)**: every version, newest first.
- **[GitHub releases](https://github.com/Auto-Tournament/cs2-server-manager/releases)**: the notes and the `csm-linux-amd64` / `csm-linux-arm64` binaries for each version.

The GitHub release is the source of truth. The docs changelog is generated from it, so this file does not repeat the notes. See [Releasing](README.md#releasing) for how a release is cut.
